------------------------------------------
2. MAIN APP STRUCTURE
------------------------------------------

Bottom Navigation Bar with 5 tabs:
[Home] | [Pets] | [Records] | [Appts] | [Profile]


------------------------------------------
2.1 HOME / DASHBOARD (/home)
------------------------------------------

Dashboard showing:
- Quick Stats (total pets, upcoming appointments, overdue vaccines)
- Upcoming Appointments widget
- Recent Activity feed
- Quick action buttons

Navigation from Dashboard:
- Tap appointment --> Appointment details
- Tap "View All" --> respective list screens


------------------------------------------
2.2 PETS SECTION (/pets)
------------------------------------------

2.2.1 PET LIST SCREEN (/pets)
    - Grid/List view of all pets
    - Add new pet FAB button
    - Search/filter pets
    |
    v
    2.2.2 PET PROFILE SCREEN (/pets/:id)
    
    Pet Info Card showing:
    - Photo, Name, Species, Breed
    - Age, Weight, Gender
    - Details: Color, Neutered, Microchip, Birthday
    
    Health Summary Cards:
    - Vaccines card (tail style) --> Vaccines List
    - Medications card (tail style) --> Medications List
    - Weight card --> Weight History
    
    Quick Actions:
    - Export Passport (PDF)
    
    Danger Zone:
    - Delete Pet
    
    Navigation from Pet Profile:
    - Edit button --> Add/Edit Pet Screen
    - Vaccines card --> Vaccines List Screen (filtered by pet)
    - Medications card --> Medications List Screen (filtered by pet)
    - Weight card --> Weight History Screen
    - Export Passport --> Generate PDF with all health records

    2.2.3 ADD/EDIT PET SCREEN
    - Form fields: Name, Species, Breed, Gender, DOB, Weight, Color
    - Neutered toggle
    - Microchip number
    - Photo upload
    - Notes
    - Save/Cancel buttons


------------------------------------------
2.3 RECORDS SECTION (/records)
------------------------------------------

2.3.1 RECORDS LIST SCREEN (/records)
    - List of all vet records
    - Filter by pet
    - Filter by type (Checkup, Surgery, Emergency, etc.)
    - Add new record FAB
    |
    v
    2.3.2 ADD/EDIT RECORD SCREEN
    
    Form fields:
    - Title
    - Pet selection
    - Date
    - Type (Checkup, Surgery, Emergency, Dental, Grooming, Other)
    - Vet/Clinic name
    - Cost
    - Notes
    - Attachments (photos)


------------------------------------------
2.4 APPOINTMENTS SECTION (/appointments)
------------------------------------------

2.4.1 APPOINTMENTS SCREEN (/appointments)
    - Calendar view
    - List view (upcoming appointments)
    - Add new appointment FAB
    |
    v
    2.4.2 ADD/EDIT APPOINTMENT SCREEN
    
    Form fields:
    - Title
    - Pet selection
    - Date & Time
    - Location/Address
    - Vet name
    - Notes
    - Reminder settings


------------------------------------------
2.5 VACCINES SECTION
------------------------------------------

Accessed from Pet Profile --> Vaccines card

2.5.1 VACCINES LIST SCREEN (/vaccines)
    - List of all vaccines for selected pet
    - Status indicators (Up to date, Due soon, Overdue)
    - Add new vaccine FAB
    |
    v
    2.5.2 ADD/EDIT VACCINE SCREEN
    
    Form fields:
    - Vaccine name
    - Date given
    - Next due date
    - Vet name
    - Clinic name
    - Batch number (optional)
    - Notes


------------------------------------------
2.6 MEDICATIONS SECTION
------------------------------------------

Accessed from Pet Profile --> Medications card

2.6.1 MEDICATIONS LIST SCREEN (/medications)
    - List of all medications for selected pet
    - Active/Inactive toggle
    - Add new medication FAB
    |
    v
    2.6.2 ADD/EDIT MEDICATION SCREEN
    
    Form fields:
    - Medication name
    - Dosage
    - Frequency (Daily, Weekly, Monthly, As needed, Custom)
    - Frequency type (times per day/week)
    - Times per day
    - Time of day (Morning, Afternoon, Evening, Night)
    - Meal timing (Before meal, With meal, After meal)
    - Start date
    - End date (optional)
    - Prescribed by
    - Notes

------------------------------------------
4. PDF EXPORT FEATURE
------------------------------------------

From Pet Profile --> Export Passport:
- Generates PDF passport with:
  - Pet Identification Card (with photo)
  - Vaccinations list
  - Current medications
  - Health records
- Can print or save PDF


------------------------------------------
5. NOTIFICATIONS
------------------------------------------

App sends reminders for:
- Upcoming appointments
- Vaccine due dates
- Medication times
- Custom reminders

Notification types:
- Appointment reminders
- Vaccine due reminders
- Medication reminders (based on time of day settings)


==========================================
ID CARD EXPORT (PNG) - Premium Feature
==========================================
- From Pet Profile: Export ID Card button
- Shows preview dialog with ID card design
- Download button captures and shares as PNG image
- ID card includes: PawPass branding, pet photo, pet info, QR code


==========================================
SHARE PASSPORT ONLINE - Premium Feature
==========================================
- Premium users can share pet passports online via link
- Toggle switch in Pet Profile enables/disables sharing
- Generates unique share token URL
- QR code displays live passport link
- Regenerate link invalidates old links
- Web view at: https://user.github.io/repo/index.html?token=xxx


==========================================
HEALTH SUMMARY - Compact Layout
==========================================
- In Pet Profile: 3-column row showing:
  - Vaccines: Count + status (OK/overdue/due)
  - Meds: Count + Active/None
  - Weight: Current weight in kg
- Each card navigates to respective screens
